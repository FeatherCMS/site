# Feather CMS documentation

Feather CMS is still in alpha. If you'd like to try it, the [getting started guide](/docs/getting-started/run-locally/) covers both setup options: run the whole stack in Docker, or build Feather CMS with Swift and run its app processes locally while PostgreSQL and Floci stay in Docker.

We'll add more guides as the project grows. This site is open source too, so if you'd like to improve it, [send us a pull request](https://github.com/FeatherCMS/site).
